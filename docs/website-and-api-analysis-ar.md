# دليل دمشق: تحليل الموقع وتوثيق الـ API

تمت المراجعة بتاريخ 16 تشرين الأول 2026 على الموقع الحي (https://dalil-dimashq.com) وعلى الملف `docs-api/dalil-openapi.yaml` (الإصدار `2026-10-13`، مكتوب يدوياً من الكود المصدري، وليس مولّداً من مشروع حي).
**البيئة الأساسية المعتمدة هي بيئة الاختبار (Staging)**، فكل ما هو موجود عليها يُعتبر متوفراً.

---

## 0. الملخص

- **لا يوجد خادم API مخصص.** الموقع صفحة واحدة ثابتة (Single Page) مستضافة على Netlify، فيها سكربت داخلي كبير وخرائط Leaflet. يتصل الموقع **مباشرةً بـ Supabase**: جداول وعروض (Views) عبر PostgREST، ودوال قاعدة البيانات (RPC)، وخدمة تسجيل الدخول (Auth)، وخدمة التخزين (Storage). الصلاحيات تُفرض في قاعدة البيانات عبر RLS والدوال، وليس عبر ملف التوثيق.
- **بعض دوال Netlify** تتولى: صفحات تحسين محركات البحث (SEO)، وصور المشاركة، وخريطة الموقع (Sitemap)، ونموذج التواصل.
- **نظام الحجز** موثّق بالكامل في الـ API وموجود على بيئة الاختبار، لكن الموقع لا يستخدمه.
- **تقييمات الزوار غير موجودة.** النجوم على الموقع هي تصنيف الفندق الرسمي أو تقييم مأخوذ من OpenStreetMap، والموقع يقول ذلك صراحةً: "تقييمات الزوار، المؤكدة برقم الهاتف، قريباً". جدول `ratings` موجود وتراجعه صفحة الإدارة، لكن لا توجد واجهة موثّقة له.
- **ما زال غير قابل للاستخراج من الموقع الحي:** ملف شخصي للمستخدم (`profiles`)، مسار إرسال تقييم زائر، التحقق من الهاتف بـ SMS، وواجهة اقتراحات منفصلة عن نموذج التواصل. الجداول `ratings` و`featured` و`payments` و`staff` و`events` أُضيفت إلى OpenAPI من كود الإدارة.
- **معظم منطق الدليل يعمل داخل المتصفح:** البحث، والفلاتر، والترتيب، و"مفتوح الآن"، ونسبة اكتمال المعلومات، والأعداد، وأسماء الشوارع.
- **البيانات الحالية قليلة:** من أصل 920 مكاناً، 125 فيها رقم هاتف و18 لها تقييم، وهناك 4 أماكن مميّزة وعرضان فعّالان فقط، ومعظم الأماكن بلا صور.

## 1. ميزات الموقع (الوضع الحالي)

### 1.1 البنية التقنية

| الطبقة | ما هي |
|---|---|
| الاستضافة | Netlify (ملفات HTML ثابتة مع Netlify Functions) |
| البيانات | مشروع Supabase `dqaapapjdvhoaskfwxoy` (الإنتاج)، يُستعلم عنه مباشرة من المتصفح بالمفتاح العام (Publishable Key) الموجود في `/config.js` |
| الخريطة | Leaflet مع طبقات أساسية: OpenStreetMap وOSM.de وOpenTopoMap وEsri Street وEsri Imagery (مع طبقات النقل والحدود) |
| التحويل العكسي للإحداثيات | Nominatim وPhoton (komoot)، تُستدعى من المتصفح لعرض اسم الشارع حسب إحداثيات كل مكان |
| البريد | Resend (نموذج التواصل، ورموز الدخول)، حسب سياسة الخصوصية |
| الإشعارات | Firebase Cloud Messaging مذكور في سياسة الخصوصية، وغير مربوط بأي شيء حالياً |
| الخطوط | Google Fonts |
| البدائل عند الفشل | Supabase أولاً، ثم نسخة محفوظة في المتصفح، ثم `/fallback.json` (نسخة ثابتة بحجم 368 كيلوبايت تقريباً)، ثم `/api/edits` القديمة (Netlify Blobs) |
| مفاتيح التخزين المحلي | `dalil-lang` و`dalil-sort` و`dalil-base` (نوع الخريطة) و`dalil-addr-v1` (ذاكرة أسماء الشوارع)، مع علامة للجلسة "شاهد نافذة العروض" |
| ملفات أخرى | `robots.txt` يمنع `/admin/` و`/owner/` و`/api/`. لا يوجد `manifest.json` (يُرجع 404)، أي أن الموقع غير قابل للتثبيت كتطبيق ويب (PWA) |

### 1.2 الدليل العام (الصفحة الرئيسية `/`)

1. **ثنائي اللغة عربي/إنكليزي** مع التبديل بين الاتجاهين RTL/LTR. يتذكر الموقع اللغة المختارة.
2. **قسم الواجهة الرئيسية (Hero)** فيه الشعار النصي ("أول دليل سياحي متكامل لمدينة دمشق") و**عدّادات** حيّة (كل الأماكن 920، فنادق 125، مطاعم 638، مقاهي 157). العدّادات تعمل أيضاً كاختصارات للفئات.
3. **البحث** في الاسم (العربي والإنكليزي والبديل)، والمطبخ، والوصف، والمنطقة، والنوع. يعمل بالكامل داخل المتصفح.
4. **الفلاتر:**
   - الفئة: الكل، فنادق، مطاعم، مقاهي
   - أقل تقييم بالنجوم، مع تنبيه أن عدد الأماكن المقيّمة قليل
   - المنطقة، عبر حقل نصي مع اقتراحات تلقائية
   - الترتيب: "الأكمل معلومات" أو "الأعلى تقييماً" أو "الاسم أ–ي" (محفوظ)
   - مفتاح "فيه رقم هاتف"
   - "مسح الفلاتر"
5. **شريط الأماكن المميّزة.** أماكن مدفوعة الظهور تحت عنوان "★ أماكن مميّزة: اختيارات مدفوعة من أصحاب الأماكن"، وتُقرأ من العرض `featured_now`.
6. **قائمة النتائج** مع زر "عرض المزيد (10)" وتقسيم صفحات داخل المتصفح، وسطر "920 مكاناً · 125 مع رقم هاتف · 18 مُقيّم". كل بطاقة تعرض الاسم باللغتين، والنوع، والمنطقة، وشارة "مميّز"، والنجوم أو "غير مُقيّم"، والشعار أو صورة مصغرة.
7. **خريطة تفاعلية** لكل الأماكن مع التكبير والتصغير واختيار نوع الخريطة.
8. **شريط العروض والفعاليات** فيه صورة وعنوان ورابط "زيارة صفحة المحل". وتظهر **نافذة منبثقة للعروض** مرة واحدة في كل جلسة.
9. **أقسام الدعوة لاتخاذ إجراء:**
   - "عندك محل أو فندق أو مقهى؟ سجّل منشأتك أو ادخل لحسابك" ← `/owner/`
   - "ساعدنا نكمّل الدليل: ابعت ملاحظة" ← `/contact/`
10. **التذييل** فيه روابط SEO (مقاهي ومطاعم وفنادق دمشق)، وتواصل معنا، وسياسة الخصوصية، وذكر حقوق OSM مع تنبيه بأن التفاصيل قد تتغير.
11. **ملاحظة على الأداء:** عند أول تحميل تظهر لوحات الفلاتر والنتائج والخريطة فارغة لعدة ثوانٍ قبل وصول البيانات.

### 1.3 صفحة المكان (`/?p=<id>` داخل التطبيق ذي الصفحة الواحدة؛ و`/{cafe|restaurant|hotel}/{slug}-{id}` مولّدة على الخادم لأجل SEO)

- صورة غلاف في الأعلى، والشعار، والاسم بالعربية والإنكليزية، والنوع، والمنطقة، وشارة "مميّز"، والنجوم مع مصدرها ("تقييم مسجّل على الخريطة").
- **أزرار الإجراءات:** الاتجاهات (رابط Google Maps)، اتصل (`tel:`)، انسخ الرقم، الموقع الإلكتروني أو صفحة التواصل.
- **العروض الحالية** (العنوان، التفاصيل، الصورة، تاريخ "حتى").
- **معرض صور** مع عارض بملء الشاشة.
- **نظرة عامة:** جملة مولّدة تلقائياً (النوع والمنطقة والدوام) مع الوصف.
- **قائمة الخدمات والمزايا** (واي فاي، قسم عائلي، أركيلة، تكييف، موسيقى حية، دفع إلكتروني، فطور، وغيرها).
- **الموقع:** العنوان، والمنطقة، وخريطة مصغّرة، واسم الشارع مستخرج من الإحداثيات.
- **الدوام:** جدول أسبوعي مع "مفتوح الآن / مغلق الآن" وتمييز اليوم الحالي. يُستخدم موسم `regular` فقط.
- **التواصل:** أرقام الهاتف (مع زر نسخ)، وفيسبوك، وإنستغرام، والموقع الإلكتروني، والبريد.
- **"اكتمال المعلومات: X من 6"**، تُحسب في المتصفح من: الهاتف، الموقع/التواصل الاجتماعي، الخريطة، الدوام، الوصف، المطبخ.
- **المشاركة وSEO:** صفحة HTML مولّدة على الخادم مع JSON-LD وصورة مشاركة بقياس 1200×630 (`/og/{id}-{hash}.jpg`). إذا تغيّر اسم المكان أو فئته يتم تحويل الرابط (301) إلى العنوان الصحيح.

### 1.4 صفحات SEO (Netlify Functions)

- `/cafes/` و`/restaurants/` و`/hotels/`: قوائم الفئات.
- `/{list}/{area}/`: قائمة فئة ضمن منطقة واحدة (مثلاً `/restaurants/bab-sharqi/`). المنطقة غير المعروفة أو الفارغة تُحوَّل (302) إلى قائمة الفئة.
- `/sitemap.xml` (فيه صفحات الفئات والمناطق والأماكن).
- كلها تُرجع 503 إذا كانت قاعدة البيانات غير متاحة.

### 1.5 صفحة التواصل (`/contact/`)

- **حقول النموذج:**
  - الاسم
  - البريد أو رقم الموبايل
  - نوع الطلب: عام، إضافة منشأة، شراكة، أخرى
  - الرسالة (حتى 3000 حرف)
  - حقل مخفي باسم "Website" لاصطياد الرسائل الآلية (Honeypot)
- **الإرسال:** إلى **`POST /api/contact`** (دالة Netlify). تصل الرسالة إلى بريد الفريق ولا تُحفظ في قاعدة البيانات. يُحدّ من الرسائل المزعجة حسب بصمة عنوان IP خلال آخر ساعة. شكل الطلب والاستجابة موثّق أدناه وفي `docs-api/dalil-openapi.yaml`.
- **قنوات مكتوبة يدوياً في الصفحة:** واتساب (`wa.me/message/UID3HXZI4KAIF1`)، و`info@dalil-dimashq.com`، وصفحتا فيسبوك وإنستغرام، والموقع "دمشق، سوريا".
- فيها تلميح يوجّه أصحاب المنشآت إلى بوابة أصحاب المنشآت، ورسالة تأكيد بعد الإرسال ("وصلتنا رسالتك").

**عقد `POST https://dalil-dimashq.com/api/contact`** (مستخرج من كود الصفحة ومطابق لتحقق السيرفر):

| الحقل | مطلوب | القواعد |
|---|---|---|
| `name` | نعم | 2–80 حرفاً (عدّ Unicode) |
| `contact` | نعم | بريد إلكتروني، أو هاتف: `+` اختياري ثم أرقام ومسافات وأقواس وشرطات؛ بعد حذف غير الأرقام 7–15 رقماً. الأرقام العربية تُحوَّل |
| `type` | نعم | `general` أو `add_facility` أو `partnership` أو `other` |
| `message` | نعم | 10–3000 حرف |
| `website` | لا | حقل وهمي (honeypot): يُترك فارغاً. أي قيمة = سبام |

الاستجابات: `200` مع `{ok: true}` · `400 {"error":"invalid","fields":[...]}` · `400 {"error":"rejected"}` للسبام · `405 {"error":"method_not_allowed"}` · `413` الجسم كبير · `429` تجاوز حد الإرسال.

### 1.6 سياسة الخصوصية (`/privacy/`)

صفحة ثابتة ثنائية اللغة، آخر تحديث 16 تشرين الأول 2026، وعند الاختلاف تُعتمد النسخة العربية. تغطي:

- **من نحن:** السجل التجاري في دمشق رقم 0110098519.
- **المعلومات التي تُجمع:** نموذج التواصل، وحسابات أصحاب المنشآت، وحسابات المستخدمين، والحجوزات، وبلاغات الحجوزات الوهمية، والاقتراحات والتصحيحات (مع بصمة IP)، والموقع الجغرافي، والكاميرا، والإشعارات، والمعلومات التقنية.
- **التخزين في المتصفح:** لا ملفات تعريف ارتباط للتتبع، ولا أدوات تحليل من جهات خارجية.
- **الأذونات والخدمات الخارجية:** Netlify وSupabase وResend وFCM وGoogle Fonts والخرائط وNominatim وPhoton.
- **حقوق المستخدم:** مع من تُشارك المعلومات، ومدة الاحتفاظ، والحقوق وحذف الحساب، والعمر 16 سنة فأكثر.

### 1.7 بوابة أصحاب المنشآت (`/owner/`)

- **الحساب:**
  - إنشاء حساب: الاسم، والبريد، وكلمة سر من 10 أحرف على الأقل، مع تنبيه عندما تكون لغة لوحة المفاتيح عربية.
  - الدخول بالبريد وكلمة السر.
  - "نسيت كلمة السر"، وتعيين كلمة سر جديدة.
- **ربط الحساب بالمنشأة:**
  - البحث عن المنشأة بالاسم.
  - **برمز سري** (`DD-…`)، والربط فوري عبر `claim_with_code`.
  - **بدون رمز:** طلب ربط (`change_requests` من نوع `claim`)، ويتصل الفريق بالمنشأة للتحقق.
  - إن لم تكن المنشأة موجودة، يُطلب من صاحبها مراسلة الفريق على واتساب.
- **منشآتي**، و**طلباتي لهذه المنشأة** (حالة كل طلب).
- **تعديلات تظهر فوراً** (لأصحاب الاشتراك المميّز فقط حسب الـ API):
  - أرقام الهاتف
  - الدوام (بصيغة OpenStreetMap النصية مثل `Mo-Su 09:00-24:00`)
  - الموقع الإلكتروني، والبريد، وفيسبوك، وإنستغرام
  - الوصف بالعربية والإنكليزية
  - الخدمات

  تصنيف وزارة السياحة يُراجَع قبل ظهوره، ويظهر "موثّقاً" بعد الاطلاع على الترخيص.
- **تعديلات تُراجَع قبل النشر:** الاسم بالعربية والإنكليزية، والنوع (مقهى، مطعم، وجبات سريعة، فندق، بيت ضيافة، نُزُل، موتيل)، والعنوان.
- **للاشتراك المميّز (Premium) فقط:**
  - رفع الصور (تُضغط في المتصفح)
  - اختيار الغلاف والشعار
  - إنشاء العروض: العنوان، والتفاصيل، وصورة اختيارية تظهر في بانر الصفحة الرئيسية، وتاريخ "من" و"إلى" بحد أقصى 60 يوماً

  الاشتراك المميّز يُشترى خارج الموقع ("تواصل معنا للاشتراك")، ولا يوجد دفع إلكتروني.

### 1.8 لوحة الإدارة (`/admin/`)

محمية بتسجيل الدخول، وتغطي:

- **الأماكن والمحتوى:** إدارة الأماكن بالكامل، والصور، والدوام، والخدمات.
- **أصحاب المنشآت:** مراجعة طلبات التعديل والربط والحذف والبلاغات، وربط أصحاب المنشآت، وعرض/تجديد الرموز السرية للأماكن، وقائمة أصحاب المنشآت وبيانات تواصلهم.
- **الاشتراكات:** الاشتراكات **والمدفوعات** (تُسجَّل يدوياً)، والأماكن المميّزة.
- **التقييمات:** مراجعة التقييمات المعلّقة (`held`) وعدّ المحسوبة (`counted`).
- **الحجوزات:** بلاغات الحجوزات الوهمية، والحظر ورفعه، ومراقبة عدم الحضور.

## 2. توثيق الـ API مقارنةً بالموقع

### 2.1 نظرة عامة على ملف OpenAPI

| القسم | المحتوى |
|---|---|
| Directory (tables) | `places`، `areas`، `amenities`، `place_hours`، `place_amenities`، `photos`، `offers`، `featured_now`، `events`، `place_scores` |
| Owner and staff (tables) | `place_owners`، `subscriptions`، `change_requests`، `featured`، `ratings`، `payments`، `staff`، `staff_permissions` |
| Bookings (staging only) | `booking_list`، `booking_settings`، `booking_response_hours`، `booking_blackouts`، `fake_reports`، `booking_bans`، `notifications` |
| RPC: owners and staff | `claim_with_code`، `place_code`، `renew_place_code`، `set_cover_photo`، `set_logo_photo`، `decide_request`، `link_owner`، `staff_user_contacts`، `staff_owner_list`، `decide_held_ratings` |
| RPC: bookings (staging only) | `booking_availability`، `create_booking`، `cancel_booking`، `confirm_booking`، `reject_booking`، `owner_cancel_booking`، `mark_booking`، `report_fake_booking`، `reply_fake_report`، `set_booking_options`، `set_booking_enabled`، `decide_fake_report`، `lift_booking_ban`، `staff_no_show_watch`، `register_device` |
| Edge Functions | `delete-account` |
| Storage | `place-photos` (روابط عامة) |
| Website (Netlify) | صفحة المكان، قوائم الفئات والمناطق، `sitemap.xml`، `/fallback.json`، صور المشاركة `/og/`، و`POST /api/contact`، و`/api/edits` (ملغاة) |

ملاحظات عامة على الملف:

- **الأخطاء:** يجب الاعتماد على رمز SQLSTATE في الحقل `code` وليس على رمز HTTP، لأن تحويل PostgREST بينهما يختلف حسب الرمز والإصدار. رسائل الأخطاء بالإنكليزية.
- **الأدوار:** زائر، ومستخدم مسجّل، وصاحب منشأة (مجاني / مميّز)، ومحرر، ومبيعات، ومشرف، ومدير.
- **تسجيل الدخول والرفع إلى Storage** مستبعدان من التوثيق عمداً ("راجع توثيق Supabase").
- **العنوان الحقيقي للمشروع** غير مذكور في الملف (`{project_ref}`).

### 2.2 ما يغطيه الـ API ويستخدمه الموقع (متطابق)

- **الجداول:** `places` و`areas` و`amenities` و`place_amenities` و`place_hours` و`photos` و`offers` و`featured_now` و`place_owners` و`subscriptions` و`change_requests`.
- **الدوال:** `claim_with_code` و`set_cover_photo` و`set_logo_photo`.
- **أخرى:** روابط الصور العامة في Storage (ومسارات الرفع والضغط)، وواجهات Netlify الخاصة بـ SEO وخريطة الموقع و`/fallback.json` وصور المشاركة، و`POST /api/contact`، وتسجيل الدخول بالبريد وكلمة السر كما تستخدمه صفحتا `/owner/` و`/admin/`.

| 1 | **الاقتراحات والتصحيحات** ("ساعدنا نكمّل الدليل") | سياسة الخصوصية تذكر حفظ الاقتراحات مع بصمة IP، لكن الموقع يحوّل إلى `/contact/` فقط. لا توجد واجهة منفصلة على الموقع الحي. |
| 2 | **إرسال تقييم زائر** | جدول `ratings` موثّق الآن (قراءة الإدارة: `held` / `counted` + `decide_held_ratings`). لا يوجد مسار إرسال من الزائر على الموقع. |
| 3 | **بيانات الملف الشخصي للمستخدم** | بوابة أصحاب المنشآت تحفظ `display_name` في metadata تسجيل الدخول فقط. لا جدول `profiles` ظاهر. سياسة الخصوصية تذكر حقولاً إضافية للتطبيق (هاتف، سنة ميلاد، نوع حساب) غير مستخدمة على الموقع. |
| 4 | **التحقق من رقم الهاتف** | شرط للحجز ولنوع `report` حسب التوثيق الأصلي. الموقع لا يعرض شاشة تحقق SMS، فلا يمكن استخراج المزوّد أو الخطوات. |
| 5 | **البحث** | يحمّل الموقع كل الأماكن (1000 صف في كل دفعة) ويفلترها داخل المتصفح. لا توجد واجهة للبحث أو للأماكن القريبة أو للبحث النصي الكامل. |
| 6 | **القيم المحسوبة** | "مفتوح الآن"، ونسبة اكتمال المعلومات، وأعداد الفئات، و"N مع رقم هاتف · N مُقيّم"، وجملة النظرة العامة، كلها منطق داخل المتصفح بلا مقابل في الـ API. |
| 7 | **التحويل العكسي للإحداثيات** | يتم داخل المتصفح عبر خدمتي Nominatim وPhoton العامتين. |
| 8 | **صور الخريطة (Tiles)** | خوادم OSM وOpenTopoMap وEsri العامة. سياسة OSM تمنع الاستخدام الكثيف دون مزوّد خاص. |
| 9 | **الواجهة القديمة `/api/edits`** | ملغاة رسمياً، لكن الموقع العام ما يزال يقرؤها كبديل احتياطي. |
| 10 | **وثائق مذكورة لكنها غير موجودة** | `supabase/bookings.md` (قواعد الحجز ورموز الأخطاء)، وطلب الدمج المفتوح PR #20. |

### 2.4 موجود في توثيق الـ API لكنه غير موجود على الموقع

| الميزة | الواجهات | الحالة |
|---|---|---|
| **الحجوزات، جهة الزبون** | `booking_availability`، و`create_booking` (مع مفتاح منع التكرار `p_client_key`، وعرض اختياري، وملاحظة)، و`cancel_booking`، و`booking_list` | جاهزة، والموقع لا يستخدمها |
| **الحجوزات، جهة صاحب المنشأة** | `confirm_booking` و`reject_booking` و`owner_cancel_booking` و`mark_booking` (حضر / لم يحضر) و`booking_settings` و`set_booking_options` و`booking_response_hours` و`booking_blackouts` | جاهزة، وبوابة أصحاب المنشآت لا تستخدمها |
| **بلاغات الحجوزات الوهمية والحظر** | `report_fake_booking` و`reply_fake_report` و`fake_reports` و`booking_bans`، ولفريق العمل: `decide_fake_report` و`lift_booking_ban` و`staff_no_show_watch` | جاهزة؛ صفحة الإدارة فيها شاشات فريق العمل فقط |
| **الإشعارات** | جدول `notifications` (12 نوعاً)، وتعليمها كمقروءة عبر `read_at` | جاهزة، والموقع لا يستخدمها |
| **تسجيل الأجهزة للإشعارات** | `register_device` (android/ios/web) | موجودة، لا يستدعيها أحد، ولا يوجد ما يرسل الإشعارات |
| **حذف الحساب** | دالة Edge `POST /functions/v1/delete-account` | غير مستخدمة على الموقع |
| **الدخول برمز OTP عبر البريد** | Supabase Auth | الموقع يستخدم كلمة السر فقط |
| **بلاغات المستخدمين وطلبات الحذف** | `change_requests` من نوع `report` (لمستخدمين هواتفهم مؤكدة) و`remove` (لأصحاب المنشآت) | غير متاحة على الموقع |
| **نتائج تقييم الأماكن** | العرض `place_scores` (`rating_count` و`score`) | لا يستخدمه أحد |
| **دوام رمضان** | `place_hours.season = ramadan` | الموقع يطلب `regular` فقط |
| **أدوات خاصة بالإدارة** | `renew_place_code` و`set_booking_enabled` | لا يستدعيهما أحد |
| **حقول إضافية للمكان** | `fax` و`photos.caption` و`tourism_class_verified` و`tourism_class_by` | ليست كلها معروضة على الموقع |

## 3. المحتوى الثابت أو المكتوب يدوياً أو غير المربوط بالخلفية

| العنصر | مكانه | ملاحظات |
|---|---|---|
| قنوات التواصل (واتساب، البريد، فيسبوك، إنستغرام، الموقع) | ملف HTML لصفحة `/contact/` | مكتوبة يدوياً. في المقابل، الحقلان `config.js → contact.whatsapp / email` **فارغان**، لذلك تختفي أزرار واتساب والبريد من الصفحة الرئيسية ويظهر فقط رابطا أصحاب المنشآت والتواصل. |
| كل نصوص الواجهة (الشعار النصي، "قريباً"، "عن التقييمات"، شروحات بوابة أصحاب المنشآت، نصوص تسويق الاشتراك المميّز) | قاموس ترجمة داخل سكربت الصفحة | لا يوجد نظام إدارة محتوى (CMS). |
| قائمة الفئات وأنواع الأماكن وتسمياتها | خريطة `TYPES` داخل السكربت | تطابق قائمة `PlaceType` لكنها لا تأتي من الـ API. |
| التقييم بالنجوم | `places.stars` (بيانات OSM أو الوزارة) | بيانات ثابتة، **وليست تقييمات زوار**. الترتيب حسب "الأعلى تقييماً" مبني عليها. |
| الاشتراك المميّز والأسعار | نص في بوابة أصحاب المنشآت: "تواصل معنا للاشتراك" | لا أسعار ولا باقات ولا دفع. الإدارة تسجّل المدفوعات يدوياً. |
| الأماكن المميّزة | `featured_now` | ديناميكية، لكنها تُباع وتُدار خارج الموقع. |
| قائمة طبقات الخريطة، وذكر الحقوق، والتنبيهات | داخل السكربت | ثابتة. |
| سياسة الخصوصية | صفحة HTML ثابتة | **لا توجد صفحة شروط استخدام**. |
| صورة خلفية صفحة التواصل (مع ذكر المصوّر من Pexels) | ملف ثابت | |
| `/fallback.json` | نسخة ثابتة يولّدها سكربت | قد تكون قديمة مقارنةً بقاعدة البيانات. |
| العدّادات، والأماكن المميّزة، والعروض، والمناطق، والخدمات، والصور، والدوام | Supabase | **ديناميكية**: تأتي من الخلفية. |
| "اكتمال المعلومات"، و"مفتوح الآن"، وجملة النظرة العامة | حسابات داخل المتصفح | بيانات ديناميكية، لكن منطقها موجود في المتصفح فقط. |

## الملحق ب: استدعاءات الـ API في كل صفحة من الموقع

- **الرئيسية:**
  - `places` و`areas` و`featured_now` و`place_hours?season=eq.regular` و`place_amenities`
  - `offers` و`photos` (الغلاف والشعار والأماكن المميّزة)
  - روابط Storage العامة، و`/api/edits` (احتياطي)، و`/fallback.json`
  - خدمات خارجية: خوادم الخرائط، وNominatim، وPhoton
- **بوابة أصحاب المنشآت:**
  - Auth: `signUp` و`signInWithPassword` و`resetPasswordForEmail` و`updateUser`
  - الجداول: `places` و`areas` و`amenities` و`place_amenities` و`photos` و`offers` و`place_owners` و`subscriptions` و`change_requests`
  - الدوال: `claim_with_code` و`set_cover_photo` و`set_logo_photo`
  - حاوية Storage `place-photos`
- **التواصل:** `POST /api/contact`.
- **الإدارة:**
  - كل ما سبق
  - الجداول غير الموثّقة: `ratings` و`featured` و`payments` و`staff`
  - الدوال: `decide_request` و`link_owner` و`place_code` و`staff_user_contacts` و`staff_owner_list` و`decide_held_ratings` و`decide_fake_report` و`lift_booking_ban` و`staff_no_show_watch`
  - الجدولان: `fake_reports` و`booking_bans`
